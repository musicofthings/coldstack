01

Cheapest provider first

Six email finders compete. The waterfall reorders them by your observed cost-per-hit, because hit rates depend on who you're targeting — not on a vendor's published averages.

02

A hard budget cap

Set a dollar ceiling on a run and it stops there — and says so. A capped run that quietly returns fewer leads with no explanation is worse than one that refuses.

03

Free preview before you spend

Search costs nothing and returns no addresses. You see who you're about to pay to enrich, and the estimate, before a single credit is spent.

Personalisation

It cannot invent a compliment.

The defining failure of AI cold email is the fabricated detail — loved your post on scaling Postgres when no such post exists. It's worse than no personalisation, because it proves the sender is automated and careless.

Prompting a model not to do that doesn't work. So the model is handed numbered signals with source URLs, must cite the ones each line rests on, and every line is then verified in code. Unsupported numbers and names are thrown out — never rewritten.

With no signals at all, the model is never called. Nothing true to say is a correct outcome.

Signals

Sourced, dated, and decayed.

Instead of an opaque intent score, signals come from public sources and each one carries a link you can click before you quote it. Scores halve on a documented half-life, so a hire posted last week outranks the same hire six months ago.

Sending

It won't let you burn your domain.

Bulk email providers — Resend, Mailjet, SendGrid, Mailchimp and the rest — all prohibit unsolicited mail in their acceptable-use policies, and enforce by terminating accounts. So a campaign declares what it is, and only compatible senders can bind to it.

Campaign classMailbox sendersBulk ESP sendersWhy
coldallowedrefusedUnsolicited mail breaches every ESP's AUP
warmallowedrefusedSame rule; prior contact isn't consent
opt_inallowedallowedPeople subscribed — an ESP is the right tool
transactionalallowedallowedReceipts, resets, the app's own mail
Enforced twice

In code and in the database

A Postgres trigger refuses the binding as well as the application layer, because a bug here costs someone their sending account — not a recoverable error.

Ramp

5 sends/day, +15%/day

Enforced, not advised. A fresh domain that sends 500 on day three is dead, and no amount of good copy recovers it.

Breakers

Pauses without you watching

Authentication break pauses immediately. Bounce rate at 3% quarantines the mailbox. 200 sends with zero replies throttles — that's silent spam-foldering.

Deliverability

An instrument panel, not a toggle.

The failures that actually kill domains are quiet ones — an SPF record that exceeds its DNS-lookup budget silently becomes a permerror, and stops working while still looking correct.

dns doctor · sending domain not safe to send 
[ OK  ] MX: 5 host(s), primary aspmx.l.google.com
[ FAIL] SPF lookups: 12 DNS lookups (limit 10)
         fix: over the limit is a permerror, so SPF stops working entirely
              even though the record looks fine. Flatten includes.
[ OK  ] SPF policy: -all (hard fail)
[ WARN] DKIM: selector google; key looks under 1024 bits
[ OK  ] DMARC: p=reject
[ WARN] Tracking domain shares the root domain with the sender
[ OK  ] Blocklist: not listed on Spamhaus DBL

A check that couldn't run reports unknown, never ok. An inconclusive report is not a green light.

Get started

Two commands, no signup.

Demo mode runs the entire pipeline against deterministic fake providers, so you can see what it does before you paste a single key.

$ git clone https://github.com/musicofthings/coldstack && cd coldstack
$ make setup     # writes .env with a generated CREDENTIAL_MASTER_KEY
$ make up        # db, redis, api, web → localhost:3000

# or skip Docker entirely:
$ cd services/worker && pip install -r requirements.txt
$ python -m coldstack.cli build --demo --limit 200 --only-valid --out leads.csv

Bring your own keys for Apollo, Hunter, an LLM, and your own mailboxes. ColdStack ships no contact data and never will — it's a pipeline you point at providers you already have agreements with.
