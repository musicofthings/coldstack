# Landing page

`index.html` is the project's landing page. One self-contained file — no build step, no
dependencies beyond a Google Fonts stylesheet.

To serve it on GitHub Pages: **Settings → Pages → Source: deploy from a branch → `main`
/ `/site`**.

The page shows real output from the tool (the cost ledger, the DNS doctor report, the
personalisation verification gate) rather than mockups. If those formats change, update
the page — a landing page showing output the software no longer produces is worse than
no landing page.
